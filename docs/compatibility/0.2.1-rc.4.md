## rc.3 → rc.4 source differences and seam survival

This bump required **no decoration change**, because rc.4 carries **no source change at all** relative to rc.3. Every `@deepseek-ai/dsh-*` package was downloaded from the registry and compared file-by-file by SHA-256 against the rc.3 tree already installed in this repository. The only differing files are:

1. each package's `package.json` (version fields only), and
2. `@deepseek-ai/dsh-client-modules/lib/index.js`, where one embedded build-commit marker changes `be72761` → `ec17a2c` at identical file length (42376 bytes) with no logic difference.

The official Workspace Client is byte-identical between the two generations: **232824 bytes**, SHA-256 `9c2c17a66a5c20de00ac2852cb76debb5237439e97f877403bcaa2a471086544` — the same digest the rc.3 gate already pinned. The gate therefore moved the *version* constants (`WORKSPACE_UI_VERSION` / `WORKSPACE_LOCALE_VERSION` in `scripts/workspace-sidebar-upstream.mjs:5-6`) while the SHA-256 constant stayed unchanged, which is a real check rather than an assumption: had the artifact differed, the gate would have rejected the build.

All eight required text seams reach the derived source: `__dshGitWorktreeManagedGuard`, `dshGitWorktree.managed`, `dshGitWorktree.state.working`, `managedWorktreeDecoration`, `ManagedWorktreeIdentity`, `__dshGitWorktreeProtected`, `__dshGitWorktree`, `data-managed-worktree`. `visibleSessionMenuItems` is absent from upstream on every generation because that identifier is introduced *by the plugin's own decoration*; its seam is `replaceIfPresent` and its absence is the expected, unchanged case.

## A baseline publish-gate failure fixed in passing

On the pre-existing `master` baseline, `pnpm run check:publish` **failed** before any of this round's edits: `scripts/check-publish.mjs` still enumerated 38 strict Remote methods while `./remote` already exposed 39 — `returnToLocal` had been added for the "return to Local" capability but the gate's expected-array was never extended. `git diff --stat master -- scripts/check-publish.mjs src/console-remote/ tests/console-remote.test.ts` was empty, proving the mismatch was inherited and not introduced by the rc.4 bump. The array in `scripts/check-publish.mjs:146` now lists `returnToLocal` in descriptor order, and the gate reports `39 methods`.

## Residual risks

- The decoration path still relies on exact text seams in the official compiled Client. Each upstream bump requires re-running the version/SHA gate and the seam probe; a silent seam drift fails closed at build time, not at runtime. A version-number-only republish like rc.4 is the *best* case, not a reason to skip the probe next time.
- Compatibility was exercised on Windows only. The macOS-only cases (newline-in-path identity reads, executable-bit resource preservation) did not run here.
- Passing build and unit tests on rc.4 packages is source compatibility, not runtime acceptance on a launched Host.
